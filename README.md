# 💎 Maison Joaillerie

### Site vitrine de joaillerie — Design élégant et responsive

**Maison Joaillerie** est un site vitrine moderne dédié à la présentation de collections de bijoux.

Ce projet a été développé avec HTML, CSS et JavaScript afin de proposer une expérience utilisateur élégante, intuitive et adaptée aux différents appareils.

🔗 **[Voir le site en ligne](https://soukachar.github.io/sitejoallerie/)**

## ✨ Fonctionnalités

- **Page d'accueil élégante** avec une grande image de présentation et des animations.
- **Navigation responsive** adaptée aux ordinateurs, tablettes et smartphones.
- **Menu déroulant** permettant d'accéder aux différentes collections.
- **Catalogue de bijoux** organisé en trois catégories : Bagues, Colliers et Bracelets.
- **Filtres interactifs** pour afficher les collections par catégorie.
- **Recherche de collections**.
- **Aperçu des bijoux** dans une fenêtre interactive.
- **Section de présentation** de l'univers de Maison Joaillerie.
- **FAQ interactive** pour répondre aux questions fréquentes.
- **Formulaire de contact fonctionnel** permettant de recevoir les demandes par email grâce à FormSubmit.
- **Animations CSS** et effets visuels pour améliorer l'expérience utilisateur.

## 🛠️ Technologies utilisées

| Technologie | Utilisation |
|---|---|
| HTML5 | Structure des pages |

| JavaScript | Interactions et filtres |

## 🎨 Design

Le site utilise une palette de couleurs inspirée de la joaillerie haut de gamme :

- Marron chocolat : `#4b2e24`
- Marron foncé : `#291913`
- Doré caramel : `#c99857`
- Crème : `#faf4ec`

L'objectif est de proposer une identité visuelle chaleureuse, raffinée et intemporelle.

## 📱 Responsive Design

Le site est conçu pour s'adapter aux différentes tailles d'écran :

- Ordinateurs
- Tablettes
- Smartphones

Les grilles, les images et la navigation s'adaptent à la taille de l'écran.

## 📧 Formulaire de contact

Le formulaire permet aux visiteurs de transmettre :

- Leur nom complet
- Leur adresse email
- Le sujet de leur demande
- Leur message

Les données sont envoyées par l'intermédiaire de **FormSubmit**, qui transmet les demandes à une adresse email configurée.

## 🚀 Installation

1. Cloner le dépôt :

```bash
git clone https://github.com/soukachar/sitejoallerie.git
```

2. Ouvrir le dossier du projet dans Visual Studio Code.

3. Ouvrir le fichier `index.html` dans un navigateur ou utiliser l'extension **Live Server**.

Aucune installation de dépendances n'est nécessaire pour exécuter la partie front-end.
